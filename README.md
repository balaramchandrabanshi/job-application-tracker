# Job Application Tracker

A web application for tracking and managing job applications.

## Planned Features

- Dashboard
- Add job applications
- View application details
- Edit applications
- Delete applications
- Search applications
- Filter applications by status
- Dashboard statistics
- Persistent data
- User authentication

## Tech Stack

### Frontend
- React
- React Router
- Context API
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
